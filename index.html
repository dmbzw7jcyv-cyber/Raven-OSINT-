Features

Everything you need to gather intelligence from public sources.

Username Search — 50+ Platforms

Search 50+ platforms simultaneously with threaded requests. Includes social media, gaming, professional, and content platforms. Extracts profile titles, descriptions, and follower counts.

Email Breach Check

Check if an email has appeared in known data breaches using privacy-preserving SHA-1 hashing against the Have I Been Pwned database. Includes domain risk pattern analysis.

Domain Intelligence

Complete domain analysis: DNS records, SSL certificates, nameservers, technology stack detection, and subdomain enumeration via certificate transparency.

Port Scanner

Threaded port scanner covering 24 common ports. Service identification and banner grabbing included for accurate results.

Deep Metadata Extraction

Extract SHA-256 hashes, EXIF data, GPS coordinates, PDF metadata, DOCX metadata, MIME type detection, and interesting strings from any file.

IP Geolocation

Get location data, ISP information, and network details for any IP address using the ip-api.com service.

Phone Analysis

Validate and analyze phone number formats, country codes, and structure.

Report Generation

Generate formatted markdown reports and CSV exports from any search. Save results for documentation and sharing.

Requirements

What you need to run Raven.

  • Python 3.8 or newer
  • Windows, macOS, or Linux
  • Internet connection for live searches
  • The requests library
  • dnspython (optional, for enhanced domain lookups)
  • Pillow (optional, for enhanced metadata extraction)

Installation

Get Raven running in under a minute.

# Clone the repository git clone https://github.com/yourusername/raven.git cd raven # Install dependencies pip install requests dnspython Pillow # Run Raven GUI python raven.py # Or run Raven CLI python raven.py --cli
