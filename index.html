Raven

Open Source Intelligence Framework

Username search · Email breach check · Metadata extraction · IP geolocation · Phone analysis

Features

Raven is a modular OSINT tool built for security researchers, investigators, and anyone who needs to gather intelligence from public sources.

Username Search

Search 21 platforms simultaneously to find where a username exists across the internet.

Email Breach Check

Check if an email has appeared in known data breaches using privacy-preserving SHA-1 hashing.

Metadata Extractor

Pull hidden metadata from images, documents, and other files including strings and EXIF data.

IP Geolocation

Get location data, ISP information, and network details for any IP address.

Phone Analysis

Validate and analyze phone number formats, country codes, and structure.

Config Persistence

Save your previous searches and preferences locally for quick access.

Requirements

  • Python 3.8 or newer
  • Windows, macOS, or Linux
  • Internet connection for live searches
  • The requests library
